# Inbound synthetic performance — 2026-10-27

This is a local measurement of the bounded synthetic path, not a production
scalability claim.

Method: CPython 3.15.2 through `uv run --locked`; one temporary SQLite
database; 1,000 deterministic `EmailMessage` messages with a small text body;
`SyntheticMailboxSource`; `InboundService.ingest(batch_limit=1000)`; timing
measured with `time.perf_counter()` around store creation and ingestion; no
network, IMAP, SMTP, DNS, or external mailbox access.

Observed result:

| Messages | Elapsed | Throughput | SQLite file |
| ---: | ---: | ---: | ---: |
| 1,000 | 3.575194 s | 279.71 messages/s | 2,613,248 bytes |

The result includes SQLite acquisition, parsing, classification, correlation
lookups, action persistence, and operational events on this development
machine. It does not establish provider latency, multi-process throughput,
retention cost for raw MIME, or production reliability.
